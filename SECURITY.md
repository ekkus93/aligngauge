# Security Policy

## Supported versions

AlignGauge has not released a stable version. Security fixes are applied to the current development branch until a supported-release policy is published.

## Reporting a vulnerability

Do not open a public issue for vulnerabilities involving malformed-input handling, memory safety, dependency compromise, genomic-data exposure, implicit network access, or output-integrity failures.

Use GitHub's private vulnerability reporting feature when available. Otherwise contact the repository owner privately through the contact method listed on the owner's GitHub profile.

Include the affected commit, reproduction steps, impact, and whether sample genomic data are involved. Do not attach identifying genomic data unless explicitly requested through a secure channel.
