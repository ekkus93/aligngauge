# MultiQC Picard discovery fixtures

These files are **parser-discovery fixtures only** for the pinned MultiQC 1.35 Picard module.

They deliberately contain small, synthetic, internally plausible tables with the exact upstream discovery markers and parser-required columns for:

- Picard `CollectWgsMetrics` / `WgsMetrics`;
- Picard `CollectHsMetrics` / `HsMetrics`.

They are not generated by AlignGauge, are not Picard differential baselines, and must never be cited as evidence that AlignGauge computes Picard WGS or hybrid-selection metrics. Their only purpose is to make upstream parser discovery and required-field drift executable in CI while the exact compatibility collectors remain gated by the Milestone 13 overlap-correction work.

A change to these fixtures is acceptable only when the pinned MultiQC/Picard profile changes or when an upstream parser requirement was previously modeled incorrectly. The parser validation must continue to run in a network-isolated container and fail closed when either fixture is not discovered.
